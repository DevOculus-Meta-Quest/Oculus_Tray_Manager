# Oculus Tray Tool

**Oculus Tray Tool** is a free utility designed to help you get the most out of your Oculus Rift and Quest headsets. It offers a wide range of features to automate tasks, manage settings, and improved your VR experience.

## Features

*   **Service Management**: Easily stop and start the Oculus Runtime service.
*   **Audio Switching**: Automatically switch audio devices when VR starts and stops.
*   **Power Management**: Manage Windows power plans to prevent USB sleep issues.
*   **Voice Commands**: Control the tool and other functions using your voice.
*   **SteamVR Integration**: Manage SteamVR settings and launch games directly.
*   **Super Sampling**: Adjust pixel density for sharper visuals.
*   **Library Management**: Organize and launch your VR games from a unified library.

## Installation

1.  Download the latest release from the [Releases](https://github.com/DevOculus-Meta-Quest/Oculus_Tray_Manager/releases) page.
2.  Extract the zip file.
3.  Run `OculusTrayTool.exe`.

## Build from Source

**Requirements:**
*   Visual Studio 2022 (or compatible)
*   .NET Framework 4.8 Developer Pack

**Steps:**
1.  Clone the repository:
    ```bash
    git clone https://github.com/DevOculus-Meta-Quest/Oculus_Tray_Manager.git
    ```
2.  Open `OculusTrayTool.sln` in Visual Studio.
3.  Restore NuGet packages.
4.  Build the solution (Release | Any CPU).
